# Features (v2)

**Layouts** 1×1, 2×1, 3×1, 1×2, 1×3, 2×2, 3×2, 2×3, 3×3, custom (rows × columns, up to 8×8). Gap, margin, corner radius, outline width/colour, row/column size weights.
**Photos** per-photo zoom, pan, rotate, flip, fit-to-frame, fill, reset; auto-fill with focal-point placement; ordering by name / file date / manual.
**Enhancement** brightness, contrast, saturation, warmth, sharpness, grayscale, blur; presets: B&W, Vivid, Warm, Cool, Fade, Vintage, Drama, Dreamy.
**Text** unlimited text boxes; fonts incl. user-loaded font files; size, colour, bold/italic, alignment, outline, shadow, background box, opacity, rotation.
**Timestamp** tokens `YYYY YY MMMM MMM MM M dddd ddd DD D HH H hh h mm ss A a`, `[literal]` escapes; live clock or fixed time; optional location and caption lines.
**Emoji / logo / watermark** movable, resizable, rotatable; username watermark text; image logo/signature with opacity.
**Backgrounds** solid, gradient (angle), blurred photo, custom image, transparent; palette extraction → background / frame / text.
**Layers** select, reorder, lock, hide, duplicate, delete.
**Designs** Story, Reel (9:16, 1080×1920), Post (4:5, 1080×1350), Square (1080×1080); safe-area overlay.
**Export** native-resolution rendering at 1× (1080 wide) or 1.333× (1440 wide); JPG/PNG/WebP; quality slider; JPG backdrop colour; file-name prefix with timestamp; folder picker; batch export.
**Projects** save/open `.cmjstory.json` (images embedded), templates (built-in + saved), duplicate design, crash recovery.
**Interface** four interface designs (Dark Creative Studio, Clean Minimal, Premium Gradient, Compact Portable), UI scale, shortcuts, toasts, status bar, undo/redo.

**Four interface designs** Dark Creative Studio (default), Clean Minimal Studio, Premium Gradient Studio, Compact Portable Workspace.
